# Semester 2
In Semester 2 I built a SOHO (Small Office Home Office).
In this semester there was more documentation required and not only test you needed to prove and show these things.

This time I learned and started using Cisco equipment, Windows Servers, file sharing, backups and basic redundancy.

### This is what we needed to have to pass:
- Perform a requirements analysis and create an internet subscription recommendation for a customer.
- Build and configure the network according to the provided topology.
- Configure Cisco network devices with basic settings and SSH management.
- Configure a home router as an access point with a separate guest network.
- Create and store backups and device configurations centrally.
- Configure Active Directory users, groups, shares and permissions.
- Demonstrate access to network resources and peripheral devices through the switched network.
- Implement basic redundancy and failover functionality for domain controllers.
- Demonstrate knowledge of basic security measures such as antivirus software, firewalls and multi-factor authentication.
- Demonstrate knowledge of a common networking model such as OSI.
- Document all results and tests in a test report.

Compared to Semester 1, this semester was a lot more complicated, introducing new concepts, hardware and software.

Looking back, this semester improved my understanding of systems and networking.
It also showed me how useful documentation can be when it is done properly.
