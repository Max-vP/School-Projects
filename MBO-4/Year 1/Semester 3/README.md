# Semester 3

In Semester 3, we worked in pairs and continued building on the networking, server and system administration skills learned in previous semesters.

This semester introduced more advanced networking concepts such as IPv6, DHCP failover, NTP and redundancy. We also started working with TOPdesk and learned the basics of Service Desk processes and ticket management.

Besides the technical aspects, we were also required to create a software recommendation for the customer. This involved comparing different software solutions based on features, usability, cost and business requirements.

During the project, we used Trello to plan tasks, divide responsibilities and track our progress.

At the start of the project, we spent quite some time troubleshooting and correctly configuring the servers. During the final project week, some of the requirements were changed, which resulted in an additional peer review.

### This is what we needed to have to pass:
- Configure and verify IPv4 and IPv6 networking.
- Configure routers, switches and VLANs according to the provided topology.
- Configure IPv6 Link-Local communication between routers.
- Configure DHCPv4, DHCP failover and SLAAC.
- Configure NTP and other infrastructure services.
- Configure and manage Windows Servers and Active Directory.
- Configure Hyper-V and virtual machines.
- Configure and test NAT and firewall rules.
- Configure and test SSH for remote management.
- Configure file shares, users, groups and permissions.
- Configure WLAN settings according to the requirements.
- Create and store centralized backups.
- Configure networked devices such as printers.
- Demonstrate knowledge of security measures and security testing.
- Work with TOPdesk and basic Service Desk processes.
- Research, compare and recommend software solutions based on cost, features, usability and business requirements.
- Document, test and validate the complete environment.
- Communicate professionally with users and team members.
- Work effectively as a team and manage tasks using Trello.

Compared to Semester 2, the network environment became larger and more complex. More focus was placed on IPv6, redundancy, documentation, testing, communication and professional IT administration.

Looking back, I learned that troubleshooting becomes much easier when you work systematically. For future projects, it would probably be better to start at the top of the topology and work through it step by step instead of working on multiple parts at the same time.

This semester also improved my teamwork, planning, documentation and communication skills.
